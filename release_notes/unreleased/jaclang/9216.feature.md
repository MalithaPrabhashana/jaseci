- **byLLM: MockLLM replies carry provider details**: `MockRawResponse(model=...)` reports the model that answered, as after a fallback; `MockError(reply=...)` streams a whole reply, any queued output, before the provider error; `MockRawResponse(unnamed_fragments=True)` streams tool-call arguments without an id or name; and `MockLLM(logging_obj=...)` attaches litellm's logging object to the stream it returns.
