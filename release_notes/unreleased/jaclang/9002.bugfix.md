- **Fix: an image built from a file or a PIL object no longer fails `jac check`** (#9002): `Image.postinit` reads `.format` and calls `.save` on the handle PIL's `Image.open()` returns. That handle is typed `ImageFile.ImageFile` in PIL's stubs, and the checker does not see the two attributes it inherits from `Image.Image`, so `jaclang/byllm/types.impl/media.impl.jac` reported 13 errors wherever pillow was actually installed. The handles are now annotated for what the checker can know about them. Behaviour is unchanged.
